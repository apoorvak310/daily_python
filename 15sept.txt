class Cat:
	def sounds(self):
		print('Meow meow')
class Dog:
	def sounds(self):
		print('bow bow')
class Rat:
	def sounds(self):
		print('keech keech')
...
if 100 classes and 100 diff methods -> reducing it to one line or two lines = polymorphism
c = Cat()
d = Dog()
r = Rat()
c.sounds()
d.sounds()
r.sounds()

list_objs = [Cat(), Dog(), Rat()]
for obj in list_objs:
	obj.sounds() #objects - respective method classes
now the code behaves diffly. one interface - many actions
